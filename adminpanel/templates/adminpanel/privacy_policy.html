Data collected

This system assigns each connecting device an anonymous identifier (displayed in a MAC-address-like format) to track point balances, bottle deposits, and WiFi session history. No personal information (name, contact number, etc.) is collected unless a user voluntarily provides it during sign-up.

Data usage

Collected data is used only to operate the reward system and to generate aggregate reports (e.g., total plastic collected) for this capstone project's evaluation. It is not shared with third parties.

Retention

Data is retained for the duration of the prototype testing period and may be cleared after project evaluation concludes.
